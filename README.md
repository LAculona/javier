# Asistente de Javier

Asistente personal que funciona en el navegador (móvil u ordenador), sin Telegram ni claves de API.

**Ábrelo aquí:** https://claude.ai/artifact/Gwmiftyf4nPsszmMYxQRyf

## Qué hace

- **Chat con Claude**: preguntas, redactar correos, resumir, planificar…
- **Tareas**: «añade tarea: renovar el DNI», con fecha límite opcional.
- **Recordatorios**: «recuérdame llamar a mamá mañana a las 18:00». Suenan en la página mientras está abierta; si estaba cerrada, ves el aviso al volver.
- **Notas**: «nota: la wifi del piso es…».
- **Memoria**: «recuerda que prefiero respuestas cortas». Lo tiene en cuenta en cada respuesta.

Todo se guarda de forma privada en tu cuenta de Claude y se sincroniza entre dispositivos.

El código está en `asistente.html`. Si lo abres directamente como archivo, funciona en "modo básico" (sin IA, guardando en el navegador).
